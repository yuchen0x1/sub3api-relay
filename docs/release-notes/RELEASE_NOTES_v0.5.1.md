# Sub3API v0.5.1

## 修复内容

- 每日支付限额纳入待支付订单预占，按充值订单实际应付金额统计，避免通过多笔待支付订单绕过限额。
- 创建订单时对同一用户串行化待支付数量和每日限额检查，避免并发请求突破待支付订单上限。
- 结账信息接口正确传播套餐查询错误，避免后端故障被显示为空套餐列表。

## 验证

- `go test ./...`
- `go test -tags=unit ./internal/service ./internal/repository ./internal/handler`
- `go vet ./...`

本版本无数据库迁移。升级前请按部署说明备份持久卷、数据库和部署配置。
