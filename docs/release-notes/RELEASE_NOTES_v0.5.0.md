# Sub3API v0.5.0

## 版本概述

管理台发现新版时可先保存编辑内容，再选择刷新或稍后处理。Linux 二进制升级支持校验构建来源，Docker 部署新增与发行版对应的 AMD64 和 ARM64 镜像。

- 管理台提供中文、英文、日文的更新提示。稍后处理会保留当前页面的编辑状态。
- Linux 升级脚本修复了自动查询最新版本时日志混入版本号的问题。替换前核对程序报告的版本，支持可选的 GitHub 构建来源验证，并以同文件系统重命名切换程序。
- 发行文件附带 SHA-256 与 GitHub 构建来源证明，Linux 镜像提供 0.5.0 和 v0.5.0 标签。
- 本版无数据库迁移。升级前备份持久卷、数据库与部署配置。

审计记录：[v0.5.0 逆向暴露面审计](EXPOSURE_AUDIT_v0.5.0.md)。
