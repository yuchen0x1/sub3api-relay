Sub3API 使用文档

这是本网关自建的中文使用文档。所有接口、密钥与 Manus 网关的使用说明都从这里开始，不再跳转任何第三方网站。

网关地址 https://your-domain.example

01快速开始

三步即可开始调用本站的 AI API 网关。

  1. 登录本站，进入 API 密钥 页面。本站默认关闭公开注册，账号由管理员创建。
  2. 创建 API Key，并选择一个分组。密钥以 sk- 开头，创建后只显示一次，请立即复制并妥善保存。
  3. 配置客户端，把 Base URL 指向你的部署地址：
    https://your-domain.example
    认证使用 Authorization: Bearer 你的APIKey 或 x-api-key: 你的APIKey。
先验证密钥 调用 GET /v1/usage 可以查看当前密钥的余额、用量和有效状态。返回 200 表示密钥可用。

02API 密钥

API Key 是调用网关的唯一凭证。每个密钥都绑定一个分组，分组决定请求会路由到哪个平台和哪些上游账号。

支持两种认证方式 Authorization: Bearer sk-xxx，或 x-api-key: sk-xxx。Gemini 兼容请求还支持 x-goog-api-key。
用量查询 GET /v1/usage，需要带同一个密钥认证，返回余额、配额与消费记录。
密钥安全 密钥丢失后无法找回，只能重新生成。请勿把密钥提交到代码仓库、聊天记录或任何公开页面。网关已弃用 query 参数传密钥（?key= / ?api_key=），请一律使用请求头。

03分组与账号

分组是网关的调度单元，也是权限边界。管理员在控制台维护上游账号，并把账号放进对应分组；用户创建 API Key 时选择分组。

  • 平台分组：Anthropic、OpenAI、Gemini、Antigravity、Grok、Manus 等，同一分组内的账号会参与负载均衡和故障切换。
  • Composite 分组：根据请求中的模型自动解析到具体平台，一个 Key 可以覆盖多种模型。
  • 并发与限速：分组和账号都支持并发数、RPM 与 Token 速率限制；超额请求会返回 429。
  • 账号状态：账号被停用、删除或达到余额阈值时，请求会返回 403 或 503，请先联系管理员。
提示 密钥绑定哪个分组，就调用哪个分组的能力。不要把同一个密钥用于多个客户端并期待自动获得未授权分组，分组由管理员统一配置。

网关同时提供 Anthropic、OpenAI 与 Gemini 兼容入口。下面的完整地址都以上方网关地址为前缀。

05Manus 网关

本站内置 Manus 网关，把 Manus 官方 v2 接口统一收口到本网关，复用 API Key 鉴权、分组调度、并发控制、限速和用量记录。

使用要求

  • API Key 必须绑定到 Manus 平台分组。
  • 该分组必须至少有一个可用的 Manus 账号，账号类型可以是 Manus API Key 或 OAuth 授权。
  • 网关地址为 https://your-domain.example/manus/v2/。

调用方式

把 Manus v2 的端点名直接放在 /manus/v2/ 后面，认证头与本站其他接口一致：

POST https://your-domain.example/manus/v2/<endpoint>
Authorization: Bearer sk-你的APIKey
Content-Type: application/json

请求会被转发到 Manus 上游，响应内容原样返回。API Key 账号自动使用上游的 x-manus-api-key，OAuth 账号自动使用 Bearer Token，无需自行拼接上游凭证。

常见错误 permission_denied 表示密钥无效；no_available_account 表示当前分组没有可用的 Manus 账号；upstream_error 表示 Manus 上游返回异常。

06客户端配置

curl 示例

curl https://your-domain.example/v1/chat/completions \
  -H "Authorization: Bearer sk-你的APIKey" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "你分组可用的模型",
    "messages": [{"role": "user", "content": "你好"}]
  }'

OpenAI SDK

Base URL 填 https://your-domain.example/v1，API Key 填本站密钥。

Claude Code

Base URL 填网关根地址，认证 Token 填本站密钥：

export ANTHROPIC_BASE_URL="https://your-domain.example"
export ANTHROPIC_AUTH_TOKEN="sk-你的APIKey"

Codex CLI

OpenAI 兼容客户端把 Base URL 指向 https://your-domain.example/v1，使用 /responses 或 /chat/completions 路径。若客户端需要 OpenAI 格式模型目录，可直接访问 GET /v1/models。

ChatBox / OpenCat 等桌面客户端

选择 OpenAI 兼容供应商，填写上面的 Base URL 和密钥即可。若客户端要求区分平台，请使用与密钥分组对应的模型名。

反向代理注意 如果本网关前面使用 Nginx，且需要多账号粘性会话，请在 Nginx 的 http 块开启 underscores_in_headers on;，否则带下划线的请求头会被丢弃。

07常见问题

状态码含义处理建议
401密钥无效、过期或未携带检查请求头，确认密钥完整且未复制到多余空格。
403分组被停用、删除或无权使用联系管理员检查分组状态和密钥绑定关系。
429触发并发或速率限制降低请求频率，或联系管理员调整限额。
404端点、模型或账号类型不支持确认使用与分组匹配的端点，例如 Embeddings 仅 OpenAI 分组可用。
502 / 503上游账号不可用或网关暂无可用账号稍后重试，或联系管理员检查上游账号状态。

为什么不能注册账号？

本网关是个人使用部署，默认关闭公开注册、支付与商业化功能。账号由管理员在控制台创建，然后登录使用。

为什么文档地址变了？

文档由当前部署实例自建，地址通常为 https://your-domain.example/docs/，与第三方站点无关。页脚的“文档”入口会直接打开本页。

如何查看余额和用量？

使用带密钥的请求调用 GET /v1/usage，或在站内“使用记录”页面查看。

08安全与维护

  • 始终通过 HTTPS 访问网关，不要使用 http:// 明文传输密钥。
  • 不要把 API Key 写入配置文件后公开，不要在浏览器地址栏或日志中泄漏。
  • 密钥只显示一次，遗失后请重新生成并立即更换客户端配置。
  • 本站更新后，管理员可在控制台检查版本、执行升级并验证健康状态；接口地址保持稳定，客户端无需频繁改动。
需要帮助 遇到密钥、分组或上游账号问题，请直接联系本站管理员，而不是到第三方论坛提交本站的密钥信息。
