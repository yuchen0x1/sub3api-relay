# Homepage Hero Asset

`stampede-front-herd.jpg` is the active landing-page hero photograph. It shows a real horse herd moving toward the camera through dust and is color-graded at runtime for the Sub3API blue-purple cinematic treatment.

- Source: Pexels photo 26617914, "Horses Running in Dust"
- Photographer: Mehmet Turgut Kirkgoz
